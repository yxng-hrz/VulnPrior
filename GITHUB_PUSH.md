# Publish on GitHub

Replace `YOUR_USERNAME` with your GitHub username.

```bash
git init
git add .
git commit -m "feat: initial release of VulnPrior"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/vulnprior.git
git push -u origin main
```

Recommended GitHub description:

> Business-oriented vulnerability prioritization engine: CVSS + EPSS + known exploitation + asset criticality -> explainable remediation decisions.

Recommended topics:

`cybersecurity`, `vulnerability-management`, `risk-management`, `ciso`, `fastapi`, `python`, `grc`, `epss`, `cvss`, `security-governance`
